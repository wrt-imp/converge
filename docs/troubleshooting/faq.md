# FAQ

## 适用对象

已经启动 Converge，想快速确认产品边界和使用方式的用户。

## 前置条件

建议先阅读[快速开始](../getting-started/quick-start)。

## 操作步骤

### Converge 是聊天机器人吗？

它包含聊天能力，但项目目标是教学认知状态引擎：持续记录学习证据，判断掌握、误解和下一步教学动作。

### Memory 和教学认知状态有什么区别？

Memory 保存学生偏好、事实、目标和约束；教学认知状态描述学生在知识空间中的动态位置，例如掌握度、误解和错误证据。

### RAG 和 Wiki 有什么区别？

RAG 从外部知识库检索原始资料；Wiki 用 Markdown 页面维护知识点、来源和页面关系，并由已审核页面编译知识图谱。

### 可以导入哪些知识文件？

知识库支持文本、代码、PDF 和 DOCX。导入后可在知识页面搜索，再由 Agent 检索相关片段。

### Skills 会自动加载吗？

Agent 会按需发现和加载已安装、已启用的匹配 Skill。也可以在消息中明确指定 Skill。

### 数据保存在哪里？

会话和记忆默认保存在 `.data/agent.db`；应用还会在本地保存知识、Skills 和配置数据。具体位置可在运行信息或设置中查看。

### 为什么不要把所有资料都放进 Memory？

Memory 用于稳定的长期信息；原始课程资料应放入知识库，工作方法应放入 Skills，Wiki 用于结构化、可审核的知识页面。

<InfoBox tone="tip" title="下一步建议">

先配置模型，再导入一份课程资料，最后使用苏格拉底式问答验证 Agent 是否能基于资料推进一轮学习。

</InfoBox>

## 预期结果

你能根据问题类型选择正确的能力入口，而不是把模型配置、资料检索、教学方法和长期信息混在一起。
