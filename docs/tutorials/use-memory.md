# 使用 Memory

## 适用对象

希望控制 Converge 跨对话保存哪些稳定信息，并能检查或撤回这些信息的用户。

## 前置条件

已启动桌面工作台。可先准备一条稳定且之后仍有用的偏好、目标、事实或约束。

## 操作步骤

<Flow steps={['打开 Memory', '选择保存策略', '添加或审核记忆', '搜索并维护']} />

<StepCard number="01" title="打开 Memory 页面">

在扩展能力区域进入 **Memory**。页面可以切换查看全部记忆与待审核候选，也提供记忆搜索和“仅保存在本机”状态提示。

</StepCard>

<StepCard number="02" title="选择记忆策略">

选择 **关闭记忆**、**保存前审核** 或 **自动保存**。保存前审核适合希望逐条确认的情况；自动保存仅会保存通过敏感信息、提示注入、置信度和重要度检查的候选。启用审核或自动提取可能增加一次模型请求。

</StepCard>

<StepCard number="03" title="添加或审核一条记忆">

手动添加时点击 **+ 添加**，选择事实、偏好、决定、目标或约束类型，填写一条简短且长期有效的信息并保存。若使用保存前审核策略，点击 **待审核**，阅读候选内容与原因，再选择 **保存** 或 **拒绝**。

</StepCard>

<StepCard number="04" title="搜索和清理">

在搜索框输入关键词并点击 **搜索**；点击 **全部记忆** 可返回完整列表。对不再适用的记忆点击 **删除**，系统执行软删除并保留审计关系。

</StepCard>

<InfoBox tone="note" title="Memory 保存长期信息">

Memory 适合保存偏好、长期目标、事实和约束。课程原文放入知识库，结构化知识总结放入 Wiki；对知识点的掌握度、误解和错误证据属于教学认知状态。

</InfoBox>

## 预期结果

你能控制长期记忆的保存策略，查看 Agent 已有信息和待审核候选，并搜索或软删除不再适用的记录。Memory 默认保存在本机 SQLite 数据库。

## 常见问题

### Agent 没记住我说的话怎么办？

检查策略是否设为“关闭记忆”；若使用“保存前审核”，再检查该内容是否仍在“待审核”列表。

### 什么内容适合保存？

保存以后仍然有用的稳定信息，例如回答偏好、长期目标或持续约束。一次性对话内容和整份课程材料通常不适合放入 Memory。

### 删除会立即抹除数据库记录吗？

界面删除使用软删除并保留审计关系；它不是直接清除数据库文件。
