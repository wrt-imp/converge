# 开始一轮苏格拉底式学习

## 适用对象

希望通过追问、提示和迁移练习理解一个知识点的学生。

## 前置条件

已配置可用模型；可选地准备一份知识库资料或启用“苏格拉底式问答” Skill。

## 操作步骤

<Flow steps={['说明主题', '回答问题', '接受提示', '验证迁移']} caption="一轮学习不是一次性给答案，而是根据回答更新下一步教学动作。" />

<StepCard number="01" title="说明你想理解的主题">

在对话中输入一个具体主题，例如递归、函数参数或其他课程知识点，并说明自己的疑问。

</StepCard>

<StepCard number="02" title="按问题作答">

Agent 会根据当前问题继续追问。尽量用自己的话解释，而不是只回复“会了”。

</StepCard>

<StepCard number="03" title="根据反馈继续推理">

答对时会提高难度；部分正确时保留正确部分并追问未闭合的推理；答错时增加提示并降低认知台阶；连续答错时会适时揭示答案。

</StepCard>

<StepCard number="04" title="完成迁移检查">

一轮完成后，尝试回答一个新例子，确认方法能否迁移。Agent 会总结方法并保留对话和运行证据。

</StepCard>

## 预期结果

你得到的是一条根据回答变化的教学路径，而不是固定答案。一次对话会成为下一次认知更新的证据。

<InfoBox tone="note" title="教学边界">

苏格拉底式问答不是所有请求的默认形式。你明确要求答案、篇幅或执行方式时，应以你的要求为准。

</InfoBox>

## 常见问题

如果问题太宽泛，先把它缩小到一个知识点、一个例子或一个具体错误。
