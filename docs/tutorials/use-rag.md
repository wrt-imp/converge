# 使用 RAG 检索知识

## 适用对象

希望 Agent 回答时能参考自己的课程资料、项目文档或代码的用户。

## 前置条件

已启动工作台并配置可用模型。准备一份文本、Markdown、代码、PDF 或 DOCX 文件；扫描版 PDF 当前没有 OCR 支持。

## 操作步骤

<Flow steps={['导入资料', '搜索验证', '在对话中提问', '根据结果调整']} caption="RAG 从本地知识库检索相关片段，再把它们作为回答参考上下文。" />

<StepCard number="01" title="把资料导入知识库">

在扩展能力区域打开 **知识** 页面，点击 **+ 导入文档** 并选择文件。导入后检查文档是否出现在“已索引文档”列表中，以及片段数量是否正常。

</StepCard>

<StepCard number="02" title="在知识页面验证检索">

在“搜索知识库”中输入资料里确实出现的关键词并搜索。检查结果片段、来源和相关度分数；如果没有结果，先换成原文中的词语，再确认文件格式和导入状态。

</StepCard>

<StepCard number="03" title="在对话中提出有范围的问题">

回到对话，指出刚导入的资料或具体主题，例如“根据我导入的函数讲义，解释参数默认值的规则”。问题越具体，越容易判断检索到的材料是否相关。

</StepCard>

<StepCard number="04" title="检查回答并修正查询范围">

把回答与知识页面中的原文对照。如果内容偏离资料，尝试明确文件主题、章节或关键词；也可回到知识页面查看实际命中的片段。无关或过期的文档可以从文档列表删除。

</StepCard>

<InfoBox tone="note" title="RAG 与 Wiki 用途不同">

知识库保留并检索导入资料的原文片段；Wiki 用经过整理和审核的 Markdown 页面表达知识点、来源与明确关系。可先用 RAG 查证原文，再把确认后的总结整理到 Wiki。

</InfoBox>

## 预期结果

资料在知识页面可搜索；对话能够把检索到的相关片段作为回答参考。你可以从知识页面检查实际命中的文本和来源。

## 常见问题

### 搜索没有结果怎么办？

确认文件已出现在已索引文档列表，尝试文档中原样出现的关键词。当前支持文本、代码、PDF 和 DOCX；扫描 PDF 因没有文本层或 OCR，可能无法检索。

### RAG 会把整份文件放进 Memory 吗？

不会。原始资料保存在知识库并按问题检索；Memory 用于稳定的个人长期信息。

### 检索结果正确，为什么回答仍不准确？

先检查结果片段是否覆盖问题所需内容，再把问题限定到相关概念或章节。模型回答仍需与原始资料核对。
